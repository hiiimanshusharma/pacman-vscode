# Pac-Man Extension

Adds an animated Pac-Man racing across your VS Code Webview panel!

## Features
- Run `Start Pac-Man session` from the Command Palette to spawn Pac-Man natively.
- Run `Stop Pac-Man session` to remove the panel permanently.
- Enable chasing ghosts via the `pacman-extension.enableGhosts` setting.
- Adjust movement speed via `pacman-extension.speed`.
