# Quickstart: Pac-Man Extension

## Development Setup

1. Make sure you have Node.js and npm installed.
2. Run `npm install` in the project root to install all VS Code extension dependencies.
3. Open this folder in Visual Studio Code.
4. Press `F5` to open a new Extension Development Host window.
5. In the new window, open the Command Palette (`Ctrl+Shift+P` on Windows/Linux, `Cmd+Shift+P` on macOS) and run `Start Pac-Man session`.
6. To modify webview assets or typescript files, you may need to run the `npm run watch` or `npm run compile` script.
